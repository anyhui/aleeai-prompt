# 开发状态

## 当前能力

- 提示词库：静态数据浏览、筛选和复制。
- 提示词生成器：浏览器本地模板生成、编辑和复制。
- 提示词优化器：用户自带密钥直连 OpenAI Chat Completions 兼容端点，支持流式输出。
- 版本历史：浏览器 `localStorage` 保存与比较，不提供账号或跨设备同步。
- 工程检查：ESLint、Vitest、Vite 构建、关键 JS 边界类型检查和 npm 生产依赖审计。
- 静态部署：Node.js 22 构建、nginx 安全响应头、缓存策略和健康检查。

## 安全边界

- 构建不接受或嵌入 API 密钥；不存在旧 `VITE_DEFAULT_API_KEY` 兼容路径。
- BYOK 密钥仅存在于当前 React 内存状态，刷新即清除。
- 远程端点需要 HTTPS，仅 loopback 本地开发允许 HTTP。
- 本仓库没有后端、账号、服务端存储、密钥托管、限流或同步能力。

## 后续工作

- 继续扩大 UI 组件的静态类型覆盖和端到端测试。
- 如需公共生产远程优化，在独立项目中实现并审计鉴权反向代理。
- 在可核实上游历史许可前，替换或补全 `public/agents.json` 的来源证据。
